## 활용

- **강의 직후**: 학습 노트 본 직후 그 강의 퀴즈로 이해 확인
- **시험·면접 대비**: 면접 문항만 골라 답안 작성
- **반복 학습**: 일주일 후 다시 — 잊은 부분 식별
- **자기 진단**: 정답 안 보고 풀어 점수

각 퀴즈 4가지 카테고리 혼합:
- 개념 — 정의·원리
- 적용 — 코드 예측·작성
- 디버그 — "왜 동작 안 하는가"
- 면접·설계 — 1분 설명·trade-off

영상 → 학습 노트 → 퀴즈 순 권장.

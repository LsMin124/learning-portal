복습 5분 / 실무 복붙 / 학습 진도 점검 세 가지 목적을 한 파일에 통합.

### 2. 3 섹션 각각의 목적

**TL;DR (5분 요약)** — 시험·면접 직전 빠른 훑기:
- 핵심 6줄: 자료에서 가장 중요한 6 가지 사실
- 가장 중요한 코드 3개: 실무에서 가장 자주 쓸 패턴
- 면접 한 줄 답변: 자주 묻는 면접 질문 4개 + 한 줄 답

**Quick Reference (실무 복붙)** — 코드 작성 중 빠른 참조:
- 문법·명령어·옵션 표
- 비교표 (vs)
- 자주 빠지는 함정 표
- 디버깅 명령

**Mind Map (전체 구조 + 체크리스트)** — 학습 진도 점검:
- ASCII 트리 (전체 토픽 한 눈에)
- 체크박스 (`- [ ]`) 형식 학습 항목
- 연관 학습 (이전 → 현재 → 다음)

### 3. 톤·길이

- TL;DR 의 6줄은 정말 6줄 (각 1~2문장)
- Quick Reference 는 빈 공간 적게, 코드와 표 위주
- Mind Map 의 트리는 ASCII 단순 문자 (`├── │ └──` 또는 `+---|---`)
- 전체 10~22KB. STUDY 와 비슷한 분량.

### 4. 핵심 원칙

- **밀도 높게**: 같은 정보 두 번 X. TL;DR 의 코드 3개는 Quick Reference 에 또 안 나옴.
- **즉시 복붙**: Quick Reference 의 코드는 변수명만 바꾸면 그대로 동작해야.
- **자료 충실**: 자료에 없는 코드 패턴 X. 자료에 있던 내용을 더 잘 정리한 것.

### 5. 금지 사항

- 자료에 없는 라이브러리/명령어 추가 금지
- "추천 공부 방법" 같은 일반 조언 X
- 같은 표를 두 섹션에 중복 X

## 출력 형식

마크다운 본문 그대로. 추가 설명·주석 없이 곧바로 `# {제목} - 치트시트` 로 시작.

각 노트의 표준 구조:
1. 이 강의는 무엇인가 / 왜 배우는가
2. 들어가기 전에 — 선수 지식, 환경
3. 핵심 개념 — 슬라이드 정의 풀어쓰기 + 코드 + 흔한 오해
4. 코드 깊게 들여다보기 — 한 줄씩 주석
5. 실전 패턴 / 함정 — ❌ → ✅
6. 자가점검 — 4문항 + 펼치는 풀이
7. 슬라이드 ↔ 노트 매핑

영상 → 슬라이드 → 노트 순서, 또는 노트만으로 처음부터 학습 가능.

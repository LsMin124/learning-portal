# Ch 26 Short-Term Finance — 치트시트

> Operating/Cash cycle / 정책 / Carrying-Shortage / Cash budget / 단기차입.

## §1 Net Working Capital

$$NWC = \text{유동자산} - \text{유동부채}$$

## §2 Operating Cycle

$$\text{Operating} = \text{Inventory period} + \text{AR period}$$

## §3 Cash Cycle

$$\text{Cash} = \text{Operating} - \text{AP period}$$

(현금 묶이는 기간)

## §4 기간 공식

| 기간 | 공식 |
|--|--|
| Inventory | 365 × 평균재고/COGS |
| AR | 365 × 평균AR/매출 |
| AP | 365 × 평균AP/COGS |

## §5 Cycle 다이어그램

```
매입──판매──회수
 │←재고→│←AR→│
 │←─Operating─→│
 지급┘
 │←AP→│←─Cash cycle─→│
```

## §6 Flexible vs Restrictive

| | Flexible | Restrictive |
|--|--|--|
| 유동자산 | 多 | 少 |
| 위험 | 낮음 | 높음 |
| 수익성 | 낮음 | 높음 |

## §7 Carrying vs Shortage

| 비용 | 자산↑ | 자산↓ |
|--|--|--|
| Carrying | ↑ | ↓ |
| Shortage | ↓ | ↑ |

$$\text{Total} = \text{Carrying} + \text{Shortage} \to \min$$

## §8 Maturity Matching

- 영구 운전자본 → 장기 자금
- 계절 운전자본 → 단기 자금
- 자산수명 = 부채만기 (헤징)

## §9 조달 전략

| 전략 | 계절자산 |
|--|--|
| Matching | 단기 |
| Flexible | 장기 (잉여 투자) |
| Restrictive | 단기 (+장기 일부) |

## §10 Cash Budget

1. Cash inflows (매출+AR 회수)
2. Cash outflows (매입/인건비/세금)
3. Net = 유입 − 유출
4. Cumulative → 차입/투자

## §11 Line of Credit

| 종류 | 특징 |
|--|--|
| Committed | 수수료, 보장 |
| Uncommitted | 비공식 |
| Compensating balance | 보상예금 (실효↑) |
| Cleanup | 일정기간 상환 |

## §12 담보 대출

| 담보 | 방식 |
|--|--|
| AR | Assigning / Factoring |
| Inventory | Blanket lien / Trust receipt / Warehouse |

## §13 Commercial Paper

- 대기업 단기 무담보 어음
- 만기 < 270일
- 은행 대출보다 저렴 (우량만)

## §14 실효이자율

$$\text{실효} = \frac{\text{이자}}{\text{실제 사용가능}}$$

- Compensating balance → 분모 ↓ → 실효 ↑
- Discount loan → 선이자 → 실효 ↑

## §15 Cash Conversion 지표

$$CCC = DSO + DIO - DPO$$

- DSO↓ (AR 회수), DIO↓ (재고), DPO↑ (AP)

## §16 자주 함정

| 함정 | 정정 |
|--|--|
| Operating = cash cycle | Cash = op − AP |
| Cash cycle 무조건 짧게 | Shortage/매출 trade-off |
| Flexible 항상 우월 | 수익성 ↓ |
| Carrying만 고려 | + shortage |
| 영구자산 단기조달 | Rollover 위험 |
| Compensating balance 무시 | 실효이자 ↑ |

## §17 핵심 mindmap

```
Short-Term Finance
├── Cash cycle = op − AP (현금 묶임)
├── 정책 (flexible vs restrictive)
├── 최적 = carrying + shortage min
├── Maturity matching (영구→장기, 계절→단기)
├── Cash budget (유입−유출)
└── 단기차입 (LOC, CP, 담보)
```

## §18 1-line summary

> **단기재무 = 운전자본. Operating cycle = inventory + AR period. *Cash cycle* = operating − AP (현금 묶임, 짧을수록 효율 but shortage 한계). 정책: flexible(자산多·안전·수익↓) vs restrictive(少·수익↑·위험↑), 최적 = carrying+shortage min. *Maturity matching* (영구→장기, 계절→단기). Cash budget(유입−유출→차입). 단기차입: LOC(compensating balance→실효↑), CP(대기업 저렴), 담보(factoring). CCC = DSO+DIO−DPO.**

# Ch 29 Mergers and Acquisitions — 치트시트

> 형태 / 시너지 / NPV (cash·stock) / 방어 / Divestiture.

## §1 인수 3 형태

| 형태 | 특징 |
|--|--|
| Merger/Consolidation | 주총 승인 |
| Stock acquisition | Tender offer (적대적) |
| Asset acquisition | 소수주주 회피 |

## §2 경제적 분류

- Horizontal (수평, 동종)
- Vertical (수직, 공급망)
- Conglomerate (복합)

## §3 시너지

$$\text{Synergy} = V_{AB} - (V_A + V_B)$$

## §4 시너지 4 원천

1. Revenue enhancement (매출)
2. Cost reduction (비용, 최신뢰)
3. Tax gains (세금)
4. Lower cost of capital

## §5 가짜 동기

- 분산 (주주 직접 가능)
- EPS bootstrapping (착시)
- 제국 건설 (agency)

## §6 Cash 인수 NPV

$$NPV = \text{Synergy} - \text{Premium}$$

$$\text{Premium} = \text{현금} - V_B$$

## §7 Stock 인수

$$\text{Cost} = \alpha \times V_{AB}$$

- α = target 결합지분율
- 시너지 클수록 비용 ↑ (공유)

## §8 Cash vs Stock

| | Cash | Stock |
|--|--|--|
| 시너지 위험 | 인수기업 | 공유 |
| 세금 | 과세 | 이연 |
| Signal | 자신감 | 과대평가? |

## §9 과세/회계

| | Taxable | Tax-free |
|--|--|--|
| 대가 | 현금 | 주식 |
| Basis | step-up | carryover |

- Goodwill = 인수가 − 순자산 FV (손상검사)

## §12 M&A 실증

- Target: +20~40% (premium)
- Acquirer: ≈ 0 / 약간 음수
- → 시너지 target 에 이전

## §13 Acquirer 실패 원인

1. Winner's curse
2. 시너지 과대평가
3. 통합 실패
4. Hubris (Roll 1986)
5. Agency

## §14 Divestiture 종류

| 형태 | 현금 |
|--|--|
| Sell-off | O |
| Spin-off | X (신주) |
| Carve-out | O (IPO) |
| Split-up | X |

## §15 왜 Divest

- Focus
- Conglomerate discount 해소
- Unlock value (부분 > 전체)

## §16 LBO

- 부채로 인수, 상장폐지
- PE/MBO
- 규율 + 세금 + 운영

## §17 자주 함정

| 함정 | 정정 |
|--|--|
| 분산 = 시너지 | 주주 직접 |
| EPS↑ = 가치 | bootstrapping 착시 |
| Synergy = 이득 | − premium |
| Stock 비용 = 주가 | α×V_AB |
| M&A = 항상 가치 | acquirer ≈ 0 |

## §18 핵심 mindmap

```
M&A
├── 형태 (merger/stock/asset)
├── Synergy = V_AB−(V_A+V_B)
│   └── 매출/비용/세금/자본비용
├── NPV: cash(syn−prem) / stock(α·V_AB)
├── 방어 (poison pill, white knight)
├── 실증 (target↑, acquirer≈0)
└── Divestiture (spin-off, LBO)
```

## §19 1-line summary

> **M&A. 형태: merger(주총)/stock(tender)/asset. *Synergy* = V_AB−(V_A+V_B): 매출/비용(최신뢰)/세금/자본비용. *Cash NPV* = synergy − premium (=현금−V_B). *Stock*: target 결합지분 보유 → 비용 = α×V_AB (시너지 공유). 방어: poison pill·staggered(사전)/greenmail·white knight(사후), agency 논란. 실증: target +20~40%, acquirer≈0 (winner's curse/hubris). 가짜동기: 분산·EPS bootstrapping. Divestiture: spin-off/carve-out (conglomerate discount 해소), LBO.**

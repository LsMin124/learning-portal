# Ch 20 Raising Capital — 치트시트

> VC / IPO / Underwriting / SEO / Rights offering.

## §1 자금 조달 단계

| 단계 | 자금원 |
|--|--|
| Bootstrap | FFF |
| Seed | Angel, accelerator |
| Series A/B/C | VC |
| Late | Growth equity |
| Exit | IPO / M&A |

## §2 VC staged financing 이유

1. Option to abandon
2. Discipline
3. Information update
4. Valuation step-up

## §3 VC term sheet

- Liquidation preference
- Anti-dilution
- Pro-rata rights
- Drag/Tag-along
- Board composition

## §4 IPO 절차

```
IB 선정 → S-1 (SEC) → Roadshow → Book building
       → Pricing → Trading → Stabilization (greenshoe)
```

## §5 Greenshoe option

- Over-allotment 15% 추가 배정권
- 수요 강 → 행사
- 수요 약 → 시장 매수 stabilize

## §6 IPO Underpricing

> First-day pop +15-20% (US)

**원인**:
1. Winner's curse
2. Info asymmetry
3. Underwriter incentive
4. Signaling
5. Cascade

## §7 IPO Long-run

- 3-5년 −15~−20% (Loughran-Ritter)
- Market timing, lock-up, window dressing

## §8 Underwriting 방식

| 방식 | 위험 부담 |
|--|--|
| Firm commitment | Underwriter |
| Best effort | Issuer |
| Dutch auction | 시장 (Google) |

## §9 Spread

| 증권 | Spread |
|--|--|
| IPO | 6-7% |
| SEO | 4-5% |
| Bond | 1-2% |
| Private placement | 1-3% |

## §10 SEO 주가 효과

> 발표 시 평균 −3%.

**Myers-Majluf**: 경영진 overvalued 판단 → equity 발행 → adverse selection signal.

## §11 Pecking Order signal 강도

| Source | Signal |
|--|--|
| Internal | 없음 |
| Debt | 작음 |
| Equity (SEO) | 가장 부정적 (−3%) |

## §12 Dilution 종류

| 종류 | 의미 |
|--|--|
| Ownership | 지분율 ↓ |
| EPS | 주식 수 ↑ |
| Book value | 발행가 < BVPS 시 |

→ 공정가 발행 시 *value dilution 없음*.

## §13 Value of a Right

$$P_X = \frac{N P_0 + S}{N+1}$$

$$\text{Right} = \frac{P_0 - S}{N+1} = P_0 - P_X$$

→ 행사 or 매도, 주주 부 불변.

## §14 발행 비용 6가지

1. Gross spread
2. Direct expenses (legal, audit)
3. Indirect (management time)
4. Abnormal returns (SEO −3%)
5. Underpricing (IPO pop)
6. Greenshoe

## §15 Shelf Registration (Rule 415)

- 한 번 등록, 2년 수시 발행
- Market timing 유연
- 비용 절감, 대기업 선호

## §16 IPO 대안

| 대안 | 특징 |
|--|--|
| Direct listing | No spread, liquidity만 (Spotify, Coinbase) |
| SPAC | Backdoor IPO (2020-21 붐, 실망) |
| Crowdfunding | Reg CF $5M, Reg A+ $75M |

## §17 Staying private longer

- Private capital 풍부 ($7T+)
- IPO 비용 (SOX, quarterly, disclosure)
- Founder control
- Secondary market (Forge, EquityZen)
- JOBS Act (2,000 shareholder)

→ Stripe, SpaceX, OpenAI 수십억 private.

## §18 자주 함정

| 함정 | 정정 |
|--|--|
| Underpricing = 비합리 | 균형 (winner's curse) |
| IPO = 좋은 투자 | Long-run underperformance |
| SEO = 호재 | −3% (Myers-Majluf) |
| Rights 무시 | 행사/매도 안 하면 손해 |
| Dilution 항상 나쁨 | 자금 용도 (NPV) 관건 |
| Direct listing = 자금 조달 | Liquidity만 (신주 X) |
| Spread만 비용 | 6가지 (underpricing 더 큼) |

## §19 핵심 mindmap

```
Raising Capital
├── Early-stage (VC, staged, convertible preferred)
├── IPO
│   ├── 절차 (S-1, roadshow, book building)
│   ├── Underpricing (+15-20%)
│   └── Long-run underperformance
├── Underwriting (firm/best effort, spread)
├── SEO (−3% signal, dilution)
├── Rights offering (right value)
└── Costs (6가지) + alternatives (direct/SPAC)
```

## §20 1-line summary

> **자본 조달 — *VC* (staged, convertible preferred) → *IPO* (underwriter, S-1, roadshow). *Underpricing* (+15-20%, winner's curse) + *long-run underperformance*. *SEO* −3% (Myers-Majluf). *Right value* = $(P_0-S)/(N+1)$. *발행 비용 6가지* (underpricing > spread). *Direct listing / SPAC* 대안. *Staying private longer* 트렌드.**

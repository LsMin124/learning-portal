# JDBC — 치트시트

> 16p 슬라이드 · 자바 표준 DB 연결 API. boards/accounts/users 스키마.
> **TL;DR** → **Quick Reference** → **Mind Map** 3 섹션.

---

# 1. TL;DR (5분 요약)

## 핵심 6줄
1. **4 단계**: `Connection` → `PreparedStatement` → `ResultSet` → `close`
2. **모든 SQL 은 PreparedStatement** (Statement 는 SQL Injection 취약 + 매번 컴파일)
3. **try-with-resources** 로 누수 방지 - JDK 7+ 표준
4. **PS 파라미터·RS 컬럼 인덱스는 1-base** (자바 배열과 다름)
5. **트랜잭션**: `setAutoCommit(false)` → ... → `commit()` / `rollback()`
6. **운영은 Connection Pool** (HikariCP) - 매 요청 `getConnection` 은 죽음

## 가장 중요한 코드 3개

```java
// (1) 표준 SELECT 4 단계
try (Connection con = DriverManager.getConnection(URL, USER, PW);
     PreparedStatement ps = con.prepareStatement(
         "SELECT id, title FROM boards WHERE user_id = ?")) {
    ps.setLong(1, userId);
    try (ResultSet rs = ps.executeQuery()) {
        while (rs.next()) {
            list.add(new Board(rs.getLong("id"), rs.getString("title")));
        }
    }
}

// (2) INSERT + 자동 생성 ID
try (PreparedStatement ps = con.prepareStatement(
        "INSERT INTO boards (title) VALUES (?)",
        Statement.RETURN_GENERATED_KEYS)) {
    ps.setString(1, "제목");
    ps.executeUpdate();
    try (ResultSet keys = ps.getGeneratedKeys()) {
        if (keys.next()) long newId = keys.getLong(1);
    }
}

// (3) 트랜잭션 (송금)
try {
    con.setAutoCommit(false);
    psWithdraw.executeUpdate();
    psDeposit.executeUpdate();
    con.commit();
} catch (SQLException e) {
    con.rollback();
    throw e;
} finally {
    con.setAutoCommit(true);
    con.close();
}
```

## 면접 한 줄 답변
- **PS 가 Statement 대비 좋은 점?** → SQL Injection 방어 + 컴파일 결과 재사용 성능.
- **try-with-resources 가 누수 막는 원리?** → 선언 역순으로 close() 자동 호출, 예외 발생해도 보장.
- **JDBC vs MyBatis vs JPA?** → JDBC (raw) → JdbcTemplate (Spring) → MyBatis (XML SQL) → JPA (ORM).
- **HikariCP 가 필요한 이유?** → 매 요청 TCP 연결 비용 (수십 ms). Pool 로 재사용.

# 2. Quick Reference (실무 복붙)

## JDBC URL

```java
String URL = "jdbc:mysql://localhost:3306/mydb"
           + "?serverTimezone=Asia/Seoul"          // 시간대 9시간 어긋남 방지
           + "&useUnicode=true&characterEncoding=UTF-8"
           + "&useSSL=false";
```

## 4 단계 정형 코드

```java
public List<Board> findAll() throws SQLException {
    List<Board> list = new ArrayList<>();
    String sql = "SELECT id, title, content FROM boards ORDER BY id DESC";

    try (Connection con = DriverManager.getConnection(URL, USER, PW);
         PreparedStatement ps = con.prepareStatement(sql);
         ResultSet rs = ps.executeQuery()) {

        while (rs.next()) {
            list.add(new Board(
                rs.getInt("id"),
                rs.getString("title"),
                rs.getString("content")));
        }
    }
    return list;
}
```

## PreparedStatement 핵심

```java
// 파라미터 바인딩 (1-base!)
ps.setLong(1, id);
ps.setString(2, name);
ps.setBigDecimal(3, new BigDecimal("1000"));
ps.setTimestamp(4, Timestamp.valueOf(LocalDateTime.now()));
ps.setNull(5, Types.VARCHAR);

// LIKE 와일드카드는 값에
ps.setString(1, "%" + keyword + "%");
```

## 실행 메서드

| 메서드 | 반환 | 용도 |
|--|--|--|
| `executeQuery()` | `ResultSet` | SELECT |
| `executeUpdate()` | `int` (영향 행 수) | INSERT/UPDATE/DELETE |
| `execute()` | `boolean` | 동적 SQL |

## ResultSet 접근

```java
// 컬럼명 (권장)
rs.getString("title");
rs.getLong("id");
rs.getTimestamp("created_at").toLocalDateTime();

// 인덱스 (1-base, 비권장)
rs.getString(1);
```

## INSERT + 자동 생성 ID

```java
PreparedStatement ps = con.prepareStatement(
    "INSERT INTO boards (title) VALUES (?)",
    Statement.RETURN_GENERATED_KEYS);
ps.setString(1, "제목");
ps.executeUpdate();
try (ResultSet keys = ps.getGeneratedKeys()) {
    if (keys.next()) long newId = keys.getLong(1);
}
```

## 트랜잭션

```java
Connection con = null;
try {
    con = DriverManager.getConnection(URL, USER, PW);
    con.setAutoCommit(false);                    // 수동 모드

    ps1.executeUpdate();   // 잔액 -1000
    ps2.executeUpdate();   // 잔액 +1000
    con.commit();

} catch (SQLException e) {
    if (con != null) con.rollback();
    throw e;
} finally {
    if (con != null) {
        con.setAutoCommit(true);                 // 풀 반환 전 복원
        con.close();
    }
}
```

## IN 절 동적 길이

```java
String ph = ids.stream().map(i -> "?").collect(Collectors.joining(","));
PreparedStatement ps = con.prepareStatement(
    "SELECT * FROM boards WHERE id IN (" + ph + ")");
for (int i = 0; i < ids.size(); i++) ps.setLong(i + 1, ids.get(i));
```

## HikariCP (Connection Pool)

```java
HikariConfig cfg = new HikariConfig();
cfg.setJdbcUrl(URL);
cfg.setUsername(USER);
cfg.setPassword(PW);
cfg.setMaximumPoolSize(10);
DataSource ds = new HikariDataSource(cfg);

try (Connection con = ds.getConnection(); ...) { ... }  // 재사용
```

```yaml
# Spring Boot 기본 HikariCP
spring.datasource.hikari:
  maximum-pool-size: 10
  minimum-idle: 5
  connection-timeout: 30000
  max-lifetime: 1800000
```

## 자주 빠지는 함정

| 함정 | 해결 |
|--|--|
| Statement + 문자열 concat | PreparedStatement |
| `con.close()` 누락 | try-with-resources |
| `autoCommit=true` 트랜잭션 | `setAutoCommit(false)` |
| `rs.getString(1)` 인덱스 접근 | 컬럼명 |
| JDBC URL serverTimezone 누락 | `?serverTimezone=Asia/Seoul` |
| PS 인덱스 0-base 착각 | 1-base (자바 배열과 다름) |
| LIKE 와일드카드를 SQL 에 | 값에 `"%" + k + "%"` |
| 매 요청 getConnection | HikariCP |

# 3. Mind Map (전체 구조 + 체크리스트)

## 전체 토픽 트리

```
JDBC (16p)
│
├── [A] 4 단계
│   ├── Connection (TCP + 인증)
│   ├── PreparedStatement (SQL 컴파일)
│   ├── ResultSet (결과 커서)
│   └── close (try-with-resources)
│
├── [B] PreparedStatement
│   ├── 파라미터 바인딩 (1-base)
│   ├── 타입별 메서드 (setString/setLong/setTimestamp)
│   ├── SQL Injection 방어
│   └── LIKE 와일드카드는 값에
│
├── [C] ResultSet
│   ├── while (rs.next())
│   ├── 컬럼명 vs 인덱스
│   └── Timestamp -> LocalDateTime
│
├── [D] CRUD
│   ├── executeQuery (SELECT)
│   ├── executeUpdate (INSERT/UPDATE/DELETE)
│   └── RETURN_GENERATED_KEYS
│
├── [E] 트랜잭션
│   ├── setAutoCommit(false)
│   ├── commit / rollback
│   └── finally close
│
└── [F] 운영
    ├── HikariCP (Pool)
    ├── DAO 패턴
    ├── 타임존 (serverTimezone)
    └── Spring JdbcTemplate (추상화)
```

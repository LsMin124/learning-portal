# 패턴 매칭 (KMP / Boyer-Moore / 라빈-카프) — 치트시트

> 68p 슬라이드 · 문자열 패턴 검색 알고리즘. N=텍스트, M=패턴.
> **TL;DR** → **Quick Reference** → **Mind Map** 3 섹션.

---

# 1. TL;DR (5분 요약)

## 핵심 6줄
1. **단순 비교**: O(N·M) 최악. 짧은 패턴엔 충분 (`String.indexOf`)
2. **KMP**: O(N+M) 안정. 실패 함수로 텍스트 포인터 안 되돌림
3. **Boyer-Moore**: 평균 O(N/M), 영문 grep 최강. 한글에선 효과 ↓
4. **라빈-카프**: rolling hash + 다중 패턴에 강함. 해시 일치 후 실제 비교 필수 (충돌)
5. **Aho-Corasick**: 다중 패턴 동시 검색 (백신 시그니처)
6. **자바 `String.indexOf`**: 평균 O(N+M), 코딩테스트 대부분 충분

## 가장 중요한 코드 3개

```java
// (1) KMP 실패 함수
static int[] failure(String p) {
    int m = p.length();
    int[] f = new int[m];
    int k = 0;
    for (int i = 1; i < m; i++) {
        while (k > 0 && p.charAt(k) != p.charAt(i)) k = f[k - 1];
        if (p.charAt(k) == p.charAt(i)) k++;
        f[i] = k;
    }
    return f;
}
```

```java
// (2) KMP 검색
static int kmp(String t, String p) {
    int[] f = failure(p);
    int n = t.length(), m = p.length(), j = 0;
    for (int i = 0; i < n; i++) {
        while (j > 0 && t.charAt(i) != p.charAt(j)) j = f[j - 1];
        if (t.charAt(i) == p.charAt(j)) j++;
        if (j == m) return i - m + 1;     // 매칭 위치
    }
    return -1;
}
```

```java
// (3) 라빈-카프 (rolling hash)
static List<Integer> rabinKarp(String t, String p) {
    int n = t.length(), m = p.length(), base = 256, mod = 1_000_000_007;
    long ph = 0, th = 0, pow = 1;
    for (int i = 0; i < m; i++) {
        ph = (ph * base + p.charAt(i)) % mod;
        th = (th * base + t.charAt(i)) % mod;
        if (i < m - 1) pow = (pow * base) % mod;
    }
    List<Integer> hits = new ArrayList<>();
    for (int i = 0; i <= n - m; i++) {
        if (ph == th && t.regionMatches(i, p, 0, m)) hits.add(i);
        if (i < n - m) {
            th = (th - t.charAt(i) * pow % mod + (long) mod * mod) % mod;
            th = (th * base + t.charAt(i + m)) % mod;
        }
    }
    return hits;
}
```

## 면접 한 줄 답변
- **KMP 의 실패 함수?** → 패턴 `p[0..i]` 의 접두사·접미사 일치 최대 길이. 실패 시 그만큼 점프.
- **Boyer-Moore 가 영어에 강한 이유?** → 알파벳 26자라 bad character 점프가 큼. 한글은 글자 다양해 효과 ↓.
- **라빈-카프에서 실제 비교가 필요한 이유?** → 해시 충돌. 다른 문자열이 같은 해시 가능.
- **실무에선 무엇?** → grep/IDE 검색은 Boyer-Moore 변형, 백신 시그니처는 Aho-Corasick, 정규식은 NFA/DFA.

# 2. Quick Reference (실무 복붙)

## 시간 복잡도 비교

| 알고리즘 | 평균 | 최악 | 전처리 | 특징 |
|--|--|--|--|--|
| 단순 비교 | O(N·M) | O(N·M) | 없음 | 짧은 패턴 |
| **KMP** | O(N+M) | O(N+M) | O(M) | 안정 |
| **Boyer-Moore** | O(N/M) | O(N·M) | O(M+Σ) | 영문 grep 최강 |
| **라빈-카프** | O(N+M) | O(N·M) | O(M) | 다중 패턴 |
| Aho-Corasick | O(N+occurrences) | 동일 | O(Σ pattern len) | 다중 패턴 동시 |

## 단순 비교 (자바 표준)

```java
"hello world".indexOf("world");       // 6
"hello world".lastIndexOf("o");       // 7
"hello".contains("ell");               // true

// 평균 O(N+M), 최악 O(N·M)
// 코딩테스트 대부분 OK
```

## KMP 실패 함수 예

```
패턴: ABABCABAB
i:    0 1 2 3 4 5 6 7 8
f:    0 0 1 2 0 1 2 3 4
```

| i | p[0..i] | 접두 = 접미 | f[i] |
|--|--|--|--|
| 0 | A | (없음) | 0 |
| 1 | AB | (없음) | 0 |
| 2 | ABA | A | 1 |
| 3 | ABAB | AB | 2 |
| 4 | ABABC | (없음) | 0 |
| 5 | ABABCA | A | 1 |
| 6 | ABABCAB | AB | 2 |
| 7 | ABABCABA | ABA | 3 |
| 8 | ABABCABAB | ABAB | 4 |

## Boyer-Moore (Bad Character)

```java
static int[] badCharTable(String p) {
    int[] table = new int[256];           // 알파벳 크기
    Arrays.fill(table, -1);
    for (int i = 0; i < p.length(); i++) {
        table[p.charAt(i)] = i;           // 가장 오른쪽 위치
    }
    return table;
}

static int boyerMoore(String t, String p) {
    int[] bad = badCharTable(p);
    int n = t.length(), m = p.length();
    int s = 0;
    while (s <= n - m) {
        int j = m - 1;
        while (j >= 0 && p.charAt(j) == t.charAt(s + j)) j--;
        if (j < 0) return s;              // 매칭
        s += Math.max(1, j - bad[t.charAt(s + j)]);
    }
    return -1;
}
```

## 알고리즘 선택 가이드

| 상황 | 선택 |
|--|--|
| 작은 텍스트 (< 1MB) | `String.indexOf` |
| 큰 영문 텍스트 (grep) | Boyer-Moore |
| 안정성 보장 필요 | KMP |
| 1000+ 패턴 | Aho-Corasick |
| 동적 패턴 + 메타문자 | 정규식 |
| DNA 분석 | Suffix Array / FM-index |
| 스트리밍 처리 | KMP / Aho-Corasick (백트래킹 X) |

## 정규식 vs KMP/BM

```java
// 정규식
Pattern p = Pattern.compile("\\d+");
Matcher m = p.matcher("abc 123 def 456");
while (m.find()) {
    System.out.println(m.group());     // "123", "456"
}
```

| | 정규식 | KMP/BM |
|--|--|--|
| 표현력 | 매우 높음 (메타문자) | 고정 패턴 |
| 속도 (단순 패턴) | 보통 | 빠름 |
| 최악 보장 | 백트래킹 시 X (ReDoS) | 항상 선형 |

⚠️ **Catastrophic Backtracking**:
```java
Pattern.compile("(a+)+b").matcher("aaaaaaaaaaaa!").matches();
// 거의 무한 루프 (ReDoS 공격 벡터)
```

## 단순 비교 최악 케이스

```
텍스트: "AAAAAAAAAAB"
패턴:   "AAAAB"

위치 0: AAAA 매칭 (4번) -> A vs B 실패
위치 1: AAAA 매칭 (4번) -> 실패
... 매번 M번 비교 -> O(N·M)
```

→ KMP 로 O(N+M) 으로 개선.

## 자주 빠지는 함정

| 함정 | 해결 |
|--|--|
| 1M 글자에 단순 비교 → TLE | KMP 직접 구현 |
| KMP 실패 함수 인덱스 헷갈림 | 0-base, `f[k-1]` 패턴 |
| 라빈-카프 해시 일치만 보고 매칭 판정 | 실제 문자열 비교 (충돌) |
| Boyer-Moore 한글 안 챙김 | char 범위 + UTF-8 byte 단위 |
| 여러 패턴을 KMP 반복 | Aho-Corasick |
| 정규식 백트래킹 폭발 | RE2 또는 패턴 단순화 |
| Suffix Tree 메모리 | 큰 텍스트엔 Suffix Array + FM-index |

## §4 기업 form 3 가지

| | Sole Prop | Partnership | Corporation |
|--|--|--|--|
| Liability | Unlimited | Unlimited (general) | Limited |
| Life | 소유자 한정 | 파트너 의존 | Perpetual |
| Tax | Personal | Pass-through | 이중 과세 |
| Transfer | 매각 | 어려움 | 자유 (주식) |
| Capital | 개인 | 파트너 합 | 무제한 (시장) |
| Form 비용 | 최소 | 중간 | 큼 |

→ 큰 회사 = C-Corp. 작은 회사 = LLC (hybrid).

## §5 LLC

- 1977 Wyoming → 2000s 일반화
- Small-medium business 의 dominant

## §7 Cash Flow 의 *3 요소*

1. **Identification** — 무엇이 cash flow
2. **Timing** — 언제 발생
3. **Risk** — 얼마나 확실

## §8 Cash flow vs Accounting income

| 항목 | Cash | Accounting |
|--|--|--|
| 현금 매출 | ✓ | ✓ |
| 외상 매출 | X (수금 시) | ✓ |
| 감가상각비 | X | ✓ (비용) |
| Capex | ✓ (outflow) | 자산 (분할 비용화) |
| 이자 | ✓ (outflow) | ✓ (비용) |
| 배당 | ✓ (outflow) | X (이익 분배) |

> Cash is fact. Profit is opinion.

## §9 Financial manager 의 Goal

> *Maximize the current value of the firm's existing stock*

- 측정 가능 (주가)
- Time + risk 모두 반영
- 장기 + 단기 통합

## §10 Stakeholder vs Shareholder

| | 전통 (Friedman) | 현대 (ESG) |
|--|--|--|
| 우선 | Shareholder | Stakeholder |
| Goal | 이익 극대화 | Long-term value |
| Other 보호 | 법 + 시장 | Firm 의 책임 |

→ Modern view: long-term shareholder = stakeholder.

## §11 Agency Problem

**Agent** (manager) vs **Principal** (shareholder).

**Conflict 의 예**:
- Perks (corporate jet, 사무실)
- Empire building (negative NPV merger)
- Risk aversion (본인 직장 vs 주주 위험 선호)
- Short-termism (bonus vs 장기)

## §12 Agency Cost 의 3 종

| | 의미 | 예 |
|--|--|--|
| Monitoring | 주주의 감시 비용 | Board, audit, regulator |
| Bonding | Manager 의 자기 구속 | Stock ownership, performance bonus |
| Residual loss | 위 둘로 해결 안 됨 | 불완전 |

## §14 Regulation 의 역사

| 연도 | 법 | 핵심 |

## §15 SOX (2002) 핵심 4

2. Internal control documentation + audit
3. Independent audit committee
4. PCAOB (auditor 감시)

## §18 Dual-class stock 의 trade-off

**찬성**: Long-term vision, takeover 방어, founder skill 보존
**반대**: Agency problem 극단, no accountability, entrenchment

→ Sunset clause (시간 제한) 의 현대 best practice.

## §19 자주 빠지는 함정

| 함정 | 실제 |
|--|--|
| Profit max = Value max | Profit 의 timing + risk 무시 |
| Accounting income = cash flow | 감가, 외상 등 차이 |
| Corporation 만 큰 회사 | LLC 가 small-medium dominant |
| Limited liability = no personal risk | Personal guarantee 흔함 |
| Agency = fraud | Subtle (perks, empire) |
| SOX = no more fraud | Theranos (private), FTX (crypto) scope 밖 |
| Stakeholder ↔ Shareholder | Long-term 일치 |
| Goal = 단기 주가 | Current value of *existing* stock = 장기 |

## §21 1-line summary

> **Corporate finance = 3 질문 의 답. *Corporation* 의 limited liability + perpetual life + 무제한 capital 이 dominant. *Cash flow* (identification + timing + risk) 가 valuation base. Goal = *주주 부 극대화*. Agency cost 의 통제. SOX + Dodd-Frank 의 regulation.**

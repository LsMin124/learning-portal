# 패턴 매칭 — KMP·Boyer-Moore·라빈-카프

> **이 강의는 무엇인가**: 문자열에서 패턴을 찾는 알고리즘 — 단순 비교, **KMP**, **Boyer-Moore**, **라빈-카프**. 알고리즘 PJT 묶음.
> **왜 배우는가**: 코딩테스트 단골. grep, IDE 검색, 백신 시그니처의 동작 원리.

---

## 들어가기 전에

- **선수**: 배열/문자열 기본, 빅오.
- **복잡도** (N=텍스트, M=패턴):
  - 단순 비교 — O(N·M) 최악
  - KMP — O(N + M)
  - Boyer-Moore — 평균 O(N/M), 최악 O(N·M)
  - 라빈-카프 — 평균 O(N + M)

---

## 핵심 개념

### 1. 단순 비교

```java
static int find(String text, String pattern) {
    int n = text.length(), m = pattern.length();
    for (int i = 0; i <= n - m; i++) {
        int j = 0;
        while (j < m && text.charAt(i + j) == pattern.charAt(j)) j++;
        if (j == m) return i;
    }
    return -1;
}
```

패턴 짧고 매칭 적으면 OK.

### 2. KMP — 실패 함수로 점프

핵심: 일부 매칭 후 실패하면 **이미 본 정보**로 패턴 점프. 텍스트 포인터는 절대 뒤로 안 감.

```java
static int[] failure(String p) {
    int m = p.length();
    int[] f = new int[m];
    int k = 0;
    for (int i = 1; i < m; i++) {
        while (k > 0 && p.charAt(k) != p.charAt(i)) k = f[k - 1];
        if (p.charAt(k) == p.charAt(i)) k++;
        f[i] = k;
    }
    return f;
}

static int kmp(String t, String p) {
    int[] f = failure(p);
    int n = t.length(), m = p.length(), j = 0;
    for (int i = 0; i < n; i++) {
        while (j > 0 && t.charAt(i) != p.charAt(j)) j = f[j - 1];
        if (t.charAt(i) == p.charAt(j)) j++;
        if (j == m) return i - m + 1;
    }
    return -1;
}
```

`f[i]` = `p[0..i]` 의 **접두사와 접미사 일치 최대 길이**.

### 3. Boyer-Moore — 뒤에서 비교 + 점프

영문에 강함. 패턴 끝에서 시작해 안 맞으면 큰 폭 건너뜀.

- **Bad character**: 안 맞은 텍스트 글자가 패턴에 없으면 패턴 전체 길이만큼 점프
- **Good suffix**: 매칭된 접미사 정보 활용

영어 알파벳 + 큰 텍스트(grep) 에서 최고. 한글은 알파벳 많아 효과 감소.

### 4. 라빈-카프 — 해시 기반

패턴 해시 미리 계산, 텍스트 윈도우 해시와 비교. 같으면 실제 문자열 비교.

```java
static List<Integer> rabinKarp(String t, String p) {
    int n = t.length(), m = p.length(), base = 256, mod = 1_000_000_007;
    long ph = 0, th = 0, pow = 1;
    for (int i = 0; i < m; i++) {
        ph = (ph * base + p.charAt(i)) % mod;
        th = (th * base + t.charAt(i)) % mod;
        if (i < m - 1) pow = (pow * base) % mod;
    }
    List<Integer> hits = new ArrayList<>();
    for (int i = 0; i <= n - m; i++) {
        if (ph == th && t.regionMatches(i, p, 0, m)) hits.add(i);
        if (i < n - m) {
            th = (th - t.charAt(i) * pow % mod + mod * mod) % mod;
            th = (th * base + t.charAt(i + m)) % mod;
        }
    }
    return hits;
}
```

**Rolling hash** — 윈도우 이동 시 전체 재계산 없이 첫 글자 빼고 새 글자 더함. 다중 패턴 검색에 강함.

### 5. 자바 내장

```java
"hello world".indexOf("world");
"hello world".contains("world");
Pattern.compile("\\d+").matcher("...").find();
```

코딩테스트 대부분 OK. 알고리즘 학습은 내장 없이.

## 코드 깊게 들여다보기

KMP 실패 함수 예 — 패턴 `"ABABCABAB"`:

```
i: 0 1 2 3 4 5 6 7 8
p: A B A B C A B A B
f: 0 0 1 2 0 1 2 3 4
```

`f[8] = 4` → 끝 4글자 "ABAB" 가 처음 4글자 "ABAB" 와 일치.

텍스트 `"ABABABCABABDABA"` 검색:
- i=4 까지 매칭(`ABAB`), text[5]='A' ≠ p[4]='C' → 실패
- f[3]=2 만큼 점프 → i 그대로, j=2 에서 다시 비교
- 텍스트 한 번 훑으면서 모든 매칭

## 실전 패턴 / 자주 빠지는 함정

- ❌ 단순 비교를 1M 글자에 → TLE.
  ✅ KMP 또는 내장.
- ❌ KMP 실패 함수 인덱스 0/1 혼동 → off-by-one.
- ❌ 라빈-카프 해시 충돌 무시.
  ✅ 해시 일치 시 실제 비교.
- ❌ Boyer-Moore 한글 안 챙김 → char 범위.
- ❌ 여러 패턴을 KMP 로 반복 → 각각 O(N+M).
  ✅ Aho-Corasick.

## 다음 강의로 가기 전 자가점검

1. KMP 실패 함수가 의미하는 바?
2. Boyer-Moore 가 영어에 강한 이유?
3. 라빈-카프 해시 일치 후 실제 비교가 필요한 이유?
4. 단순 비교 최악 입력 예?

<details><summary>풀이</summary>

1. `p[0..i]` 에서 접두사·접미사 일치 최대 길이. 매칭 실패 시 그 길이만큼 패턴 점프.
2. 알파벳 26자 → bad character 테이블 효과적. 매칭 안 된 글자가 패턴에 없으면 패턴 길이만큼 점프.
3. 해시 충돌. 다른 문자열이 같은 해시값 가질 수 있음.
4. `"AAAAAAAB"` + `"AAAB"`. 매번 거의 끝까지 매칭 후 실패 → O(N·M).

</details>

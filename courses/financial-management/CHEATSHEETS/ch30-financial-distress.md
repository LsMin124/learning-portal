# Ch 30 Financial Distress — 치트시트

> 정의 / 재무 vs 경제 / Ch7-Ch11 / APR / Workout / Z-score.

## §1 곤경 4 정의

| 정의 | 의미 |
|--|--|
| Business failure | 사업 실패 |
| Legal bankruptcy | 법적 파산 |
| Technical insolvency | 불이행 |
| Accounting insolvency | 부채>자산 |

## §2 재무 vs 경제적 곤경

| | 재무 | 경제 |
|--|--|--|
| 원인 | 부채 과다 | 사업성 상실 |
| 운영 | 건전 | 훼손 |
| 해법 | 회생 | 청산 |

## §3 대응 선택지

```
곤경
├── Workout (사적)
└── Bankruptcy
    ├── Ch 7 (청산)
    └── Ch 11 (회생)
```

## §4 Chapter 7 (청산)

- 자산 매각 → 분배 → 소멸
- Trustee 관리
- APR 적용

## §5 Chapter 11 (회생)

- 기업 존속, 부채 재조정
- DIP (기존 경영진)
- Automatic stay
- Cramdown (강제 인가)

## §6 Ch 7 vs Ch 11

| | Ch 7 | Ch 11 |
|--|--|--|
| 목적 | 청산 | 회생 |
| 기업 | 소멸 | 존속 |
| 운영 | Trustee | DIP |

## §7 APR 순서

1. 담보 채권
2. 관리 비용
3. 임금 (한도)
4. 세금/연금
5. 무담보 채권
6. 우선주
7. 보통주 (최후)

## §8 APR 이론 vs 실무

- 이론: 절대 우선
- 실무: Ch 11 협상 → 위반 (holdout)
- Franks-Torous 실증

## §9 Workout (사적)

- 채권자 협상 (법원 밖)
- 저렴·빠름
- Holdout 문제

## §10 Prepackaged

- 사전 합의 + Ch 11
- Holdout 강제 해결
- 속도 + 강제력

## §11 Workout vs Ch 11

| | Workout | Ch 11 |
|--|--|--|
| 비용 | 낮음 | 높음 |
| Holdout | 문제 | 해결 |

## §12 곤경 비용

| 직접 (작음) | 간접 (큼) |
|--|--|
| 법률/회계 | 매출 상실 |
| 자문 | 인재 이탈 |
| | 과소투자 |
| | Fire sale |

## §13 Altman Z-score

$$Z = 1.2X_1 + 1.4X_2 + 3.3X_3 + 0.6X_4 + 1.0X_5$$

| 변수 | 정의 |
|--|--|
| X₁ | 운전자본/총자산 |
| X₂ | 이익잉여금/총자산 |
| X₃ | EBIT/총자산 |
| X₄ | 자기자본시가/부채장부 |
| X₅ | 매출/총자산 |

## §14 Z-score 판정

- Z < 1.81 → 위험
- 1.81~2.99 → 회색지대
- Z > 2.99 → 안전

## §15 Distressed 투자

- Loan to own
- Fulcrum security
- Debt-equity swap

## §16 자주 함정

| 함정 | 정정 |
|--|--|
| 재무=경제 곤경 | 부채 vs 사업성 |
| 파산=청산 | Ch11 회생 |
| APR 항상 준수 | 실무 위반 |
| 곤경비용=직접만 | 간접 더 큼 |
| Ch11=경영진 퇴출 | DIP 유지 |

## §17 핵심 mindmap

```
Financial Distress
├── 정의 (4종)
├── 재무(회생) vs 경제(청산)
├── Ch 7 (청산, APR) / Ch 11 (회생, DIP)
├── APR (담보→...→보통주)
├── Workout vs prepackaged
└── 비용(직접<간접) + Z-score
```

## §18 1-line summary

> **재무 곤경. 정의 4종 (business failure/legal/technical/accounting insolvency). *재무 곤경*(부채 과다→회생) vs *경제적*(사업성→청산). *Ch 7*(청산, trustee, APR) vs *Ch 11*(회생, DIP, automatic stay, cramdown). *APR*: 담보→관리비용→임금→세금→무담보→우선주→보통주(최후), 단 Ch11 협상서 위반. *Workout*(사적, holdout) vs *prepackaged*(사전합의+Ch11). 비용: 직접<간접(매출/인재/과소투자). Altman Z = 1.2X₁+...+1.0X₅ (Z<1.81 위험).**
